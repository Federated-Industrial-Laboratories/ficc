Connect clusters through HyperNet

Each cluster keeps its own resources and policy. Prepare a dedicated HyperNet application companion for each FICC controller.

  1. Use compatible HyperNet Core and Suite with application streams (first supported feature release: 0.9.0).
  2. Enroll each application principal. Approve action 30 for the exact other service; register each protocol 7 endpoint route.
  3. Offer and accept the exact service with protocol ficc.federation/1. Its owner and endpoint operator sign the route, binding and finite limits. Register with action 29.
  4. Generate the endpoint configuration with streams endpoint-config. Run streams agent with both its accepted --binding and approved --targets.
  5. If the authority runs on another machine, start network authority-connector from its own joined profile. Use its Ingress directory as Core's --authority-connector-directory.
  6. Start Core's consented endpoint with the companion's Ingress directory as --application-directory. Keep the SDK socket private to the FICC account.
  7. In Federation, select Configure connection, then enter the companion directory and cluster label. Verify the displayed identities.
  8. Send a pairing request to an approved target. The receiving operator selects resources and limits. Complete pairing on the initiating cluster.

HyperNet commands and prerequisites

Operate and recover

Use Share local resources for reverse access and Refresh remote access to select a new grant. Browse shared resources supports prompts, cancellation, deployment previews and verified model acquisition.

Retain mutation IDs shown before dispatch. Inspect a retained operation after interruption before issuing a new action. Pause model transfers and resume the same immutable revision; only full SHA-256-verified files become usable.

Revocation cancels requests. Services already created remain locally managed unless their grant selected stop-on-revoke. Remove peer revokes its local grants and closes outgoing requests without deleting models.

A restored backup requires new companion configuration and explicit pairing. Never relax socket permissions or substitute a different identity to bypass a refusal.

The installed documentation includes docs/federation.md and sdk/federation.md with grants, limits, API and CLI details.
